The working system: Markdown, staged files and handoffs

Good prompting collapses without a place to keep the work. Day one therefore builds a small, boring system alongside the prompting, and most delegates report it is the habit that survives longest after the course.

  • Convert everything to Markdown. Rich formats carry enormous overhead. A Word file can be orders of magnitude larger than the same text, and you pay for that out of the context you needed for thinking. We cover which conversion tools are currently reliable for PDFs, slides and spreadsheets, and how to check the conversion worked.
  • One file per stage, numbered. Input saved, output saved, output becomes the next input. It reads like admin until the first time somebody asks you how a conclusion was reached.
  • Handoff prompts. When a conversation starts to drift, you ask for a self-contained summary of decisions taken and options rejected, then open a clean chat with it, which is the practical answer to context rot.
  • A governance trail. The numbered files become a reviewable record of how a piece of AI work was produced, which is what makes AI output safe to delegate inside a team or hand to a client.

We use Obsidian for this because it is free and it renders Markdown properly, though any text editor will do the same job.
